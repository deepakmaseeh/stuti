01 · VerdictSinging works. Planning a service doesn't yet.

Song pages, set mode and Present are close to ready. The set editor, the order of service and the PPT content aren't: sections are decoration (songs always land at the bottom), multi-add fails, the "PDF" is a plain list, and the deck drops headings and chorus repeats. Fix the eight P0s first. They're one data change (sections and items) plus three renderers that read from it.

Rules the renderer must follow

ElementRule
Page@page{size:A4;margin:14mm}, white background, print-color-adjust:exact. Fits about 18 rows per page; longer sets flow onto page 2 with the table header repeated (thead{display:table-header-group}).
HeaderChurch name (Settings → Church), "Order of Service", service title, copy label, QR to the set's public view link.
Meta stripDate as "Sunday, 22 November 2026" (en-IN, long). Time is start, plus end when durations are known. Leader and preacher come from the set; empty cells are hidden.
Section rowLeather band, uppercase label, time span on the right. break-after:avoid keeps it with its first row. Empty sections are skipped.
NumberingRunning number across all songs and items (1…n). Hymn column shows book code + hymn number ("TLBC 12"), never the code alone.
Title cellNative title in its script font (Noto Sans Devanagari, Tamil, Telugu or Gurmukhi), Roman title in italic beneath. Items show their reference ("Luke 2:8–14") beneath.
TimeStart time plus the running sum of minutes (song default 5, from song.minutes if set; item minutes as entered). If no time is set, hide the column.
Key / SingKey chip value. Sing = verse sequence from buildSequence(), so it matches what Present plays ("V1 · C · V2 · C").
CopiesLeader: every column. Congregation: no time, key, sing or led-by, larger titles (fit for a bulletin). Musicians: keys and sequence in bold, items greyed out.
Lyrics pagesOptional appendix, 2 columns, one song never split (break-inside:avoid). Only the verses selected in the set.
File namedocument.title = "Order of Service – Sunday Morning – 2026-11-22" before print(), which sets the PDF name in Chrome and Edge.
Footer"Prepared with Stuti", the books used, and page x of y (CSS counters work in Chrome print).

// src/lib/sets/runsheet.ts: the single source for Order of Service, Present and PPT
export function buildRunSheet(set, songsById) {
  let t = toMinutes(set.time ?? '10:00'), n = 0, section = null; const out = [];
  for (const r of set.rows) {
    if (r.k === 'h') { section = { label:r.label, start:t, rows:[] }; out.push(section); continue; }
    if (!section) { section = { label:'', start:t, rows:[] }; out.push(section); }
    const song = r.k === 's' ? songsById[r.song] : null;
    const seq  = r.k === 's' ? (r.seq ?? autoSequence(song)) : null;     // chorus after each verse
    section.rows.push({ ...r, n: ++n, at: t, song, seq });
    t += r.minutes ?? (r.k === 's' ? 5 : 3);
    section.end = t;
  }
  return out.filter(s => s.rows.length);                              // empty sections are skipped
}
export function autoSequence(song) {
  const v = song.stanzas.filter(s => s.type === 'verse').map(s => s.id), c = song.stanzas.find(s => s.type === 'chorus')?.id;
  if (!c) return v;
  const lead = song.stanzas[0].type === 'chorus' ? [c] : [];
  return [...lead, ...v.flatMap(id => [id, c])];
}
// src/lib/sets/parseAdd.ts: fixes "12, 46, 103" (C18)
export function parseAdd(input, defaultBook) {
  return input.replace(/([A-Za-z]{1,5})\s+(?=\d)/g, '$1')        // "TLBC 12" → "TLBC12"
    .split(/[\s,;]+/).filter(Boolean).map(tok => {
      const m = tok.match(/^([A-Za-z]{1,5})?(\d{1,4})$/);
      return m ? { book:(m[1] ?? defaultBook).toUpperCase(), no:+m[2], raw:tok } : { raw:tok, error:'format' };
    });
}
